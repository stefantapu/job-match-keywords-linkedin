# Privacy Policy

LinkedIn Job Match Keywords does not collect, sell, or transmit personal data.

The extension runs only on LinkedIn Jobs pages. It reads the visible job description text in the active page to calculate keyword matches locally in the browser.

Your keyword lists are stored with `chrome.storage.sync` so they can persist between browser sessions. The extension does not send your keywords or job description text to any external server.

The extension does not use analytics, tracking pixels, advertising SDKs, or remote code.
